# Rungst API examples

Small Rust examples for the [Rungst API](https://rungst.com/).

## Projects

- [Stream examples](examples/stream/): WebSocket stream examples.
  - [Callouts](examples/stream/callouts/): stream Solana callouts.
  - [Trades](examples/stream/trades/): stream Solana trades.
- [Momentum](examples/momentum/): observe thesis activity.
