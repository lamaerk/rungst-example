# Rungst API examples

Small Rust examples for the [Rungst API](https://rungst.com/).

## Examples

- [Callouts](examples/stream/callouts/): stream Solana callouts.
- [Trades](examples/stream/trades/): stream Solana trades.
- [Momentum bot](examples/bot/momentum/): observe momentum or trade with Rungst.
- [Swaps](examples/bot/swaps/): build and submit a trade.
- [Thesis bot](examples/bot/thesis/): experimental callout-driven strategy.

Each example describes its setup and environment variables in its README.
